# BarberShopLM

Sitio estático (HTML, CSS y JS) para la barbería BarberShopLM, listo para GitHub Pages.

- Librerías por CDN: GSAP + ScrollTrigger, Lenis y Three.js (importmap).
- Escena 3D procedural en `js/scene.js` (poste, navaja y tijeras con explosión 360° al hacer scroll).
- Fotos de ejemplo generadas con IA en `assets/img/`: reemplázalas por fotos reales.
- WhatsApp: cambia `50200000000` en `index.html` y `WHATSAPP_NUMBER` en `js/main.js`.
- Dirección, horarios y redes sociales: datos de ejemplo marcados con comentarios en `index.html`.
